# CORE-005 — خريطة الاستفادة الأولية من V2
الحالة: فحص ساكن جزئي؛ توصيات مرشحة وليست اعتمادًا للتنفيذ. لم يُنقل كود ولم تُشغّل اختبارات.
| القدرة | الملاحظة العامة | التوصية |
|---|---|---|
| المبيعات والسلات | خدمات مستقلة لتعديل المسودات وترحيل العمليات | نقل قواعد الأعمال بعد اختبارها؛ فصل التخزين والواجهة |
| المشتريات والمرتجعات | عمليات ترحيل وحساب كميات ومبالغ | تطوير القواعد واختبار العكس والتخصيص |
| المحاسبة والخزينة | خدمات قيود وسندات وجرد | تطوير مع ملكية المحاسبة للترحيل ومعاملة مشتركة |
| المخزون والتقييم | حسابات دقيقة وحركات وتقييم | نقل القواعد المرشحة بعد حسم O03 |
| النواقص والبحث | خدمات قراءة واستعلامات متخصصة | تحسين التجربة والأداء |
| التسعير | قوائم أسعار وسياسات تعديل؛ اكتمال قواعد الشرائح غير متحقق | تطوير محرك موحد قابل للتخصيص |
| الهوية والصلاحيات | عقود تحقق وصلاحيات وإعادة تحقق | إعادة هندسة وفق O06/O14 |
| المزامنة | قوائم إرسال واستقبال وحالات إعادة محاولة | إعادة هندسة وفق O08 |
| النسخ والاستعادة | تحقق جزئي لقدرة خاصة؛ النسخ الشامل غير متحقق | تصميم واختبار وفق O09 |
| الواجهات والتخزين | ارتباطات مباشرة بين الواجهة والتخزين في عينات الفحص | إعادة بناء الحدود والواجهات |
أي سياسة موروثة غير مثبتة في V3 مرتبطة بقرار V2 غير مؤكد. لا نقل حرفي أو قرار تقنية نهائي. الفحص ليس جردًا شاملًا للمستودع ولا إثبات سلامة تشغيل. الأدلة التفصيلية لم تحفظ بعد في مخزن خاص دائم؛ لا يدعى إغلاق بوابة CORE-005. المرحلة التالية المقترحة تحديد نطاق الإصدار الأول بعد معالجة شرط الأدلة وإقرار كفاية الفحص.

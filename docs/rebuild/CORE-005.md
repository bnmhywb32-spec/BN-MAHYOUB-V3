# CORE-005 — خريطة الاستفادة الأولية من V2
الحالة: فحص ساكن جزئي مدعوم بجرد أسماء ملفات المصدر من شجرة Git كاملة غير مقتطعة وعينات كود محددة. الأدلة الخاصة V3-CORE005-E01/E02 محفوظة في V2 الخاص. توصيات مرشحة وليست اعتمادًا للتنفيذ؛ لم يُنقل كود ولم تُشغّل اختبارات.
| القدرة | الملاحظة العامة | التوصية |
|---|---|---|
| المبيعات والسلات | خدمات مستقلة لتعديل المسودات وترحيل العمليات | نقل قواعد الأعمال بعد اختبارها؛ فصل التخزين والواجهة |
| المشتريات والمرتجعات | عمليات ترحيل وحساب كميات ومبالغ | تطوير القواعد واختبار العكس والتخصيص |
| المحاسبة والخزينة | خدمات قيود وسندات وجرد | تطوير مع ملكية المحاسبة للترحيل ومعاملة مشتركة |
| المخزون والتقييم | حسابات دقيقة وحركات وتقييم | نقل القواعد المرشحة بعد حسم O03 |

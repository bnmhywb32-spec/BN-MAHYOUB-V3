# مرجع المصطلحات والمسائل المفتوحة — V3
## المصطلحات
- الشركة: نطاق أعمال وبيانات مستقل؛ ليست بالضرورة المستأجر التقني أو الكيان القانوني.
- المجال: قواعد الأعمال المستقلة عن الواجهة والتخزين. الوحدة: مالك مسؤولية محددة. العقد: مدخلات ومخرجات وشروط معلنة، لا تنفيذ بعينه.
- حالة الاستخدام: تنسيق عملية عبر الوحدات. الأمر: طلب تغيير محدد الهوية. المعاملة الذرية: تثبيت كل الآثار المحلية اللازمة أو عدم تثبيت أي منها.
- الترحيل: تثبيت آثار المستند؛ الاعتماد: إذن وفق السياسة؛ المزامنة: نقل وتأكيد مستقلان عن الترحيل.
- مصدر الحقيقة: السجل المرجعي المعتمد؛ الإسقاط: قراءة مشتقة قابلة للمطابقة وإعادة البناء.
- منع التكرار: إعادة الأمر نفسه دون أثر إضافي؛ التزامن: إدارة أوامر متنافسة مختلفة.
- السلطة: حق اتخاذ قرار على مورد ضمن نطاق؛ التفويض: حق الفاعل في إجراء محدد؛ الحجز: تخصيص مورد دون حركة فعلية.
- التصحيح: أثر مستقل مرتبط بالأصل؛ الاستحقاق: حق أو التزام؛ التسوية: تخصيص مبلغ لمعالجة المستحق.
- العمل المحلي أولًا: تشغيل مفوض دون اتصال ضمن حدود السلطة؛ لا يعني اتساقًا لحظيًا بين أجهزة منفصلة.
## سجل المسائل المفتوحة
جميع البنود التالية غير محسومة. يحسم المسؤول الهندسي ضمن التفويض قبل البوابة المذكورة، مع توثيق البدائل والسبب والأثر والقبول؛ يرجع للمالك عند تغيير الرؤية أو التكلفة أو حدود التفويض.
| المعرف | المسألة | بوابة الحسم |
|---|---|---|
| O01 | المستأجر والكيان القانوني والملكية المشتركة | قبل مخطط الهوية النهائي |
| O02 | صيغة المعرف والتمثيل العددي والدقة والتقريب والتحويل | قبل إثبات التقنية المالي |
| O03 | سلطة المخزون وسياسة السالب والتكلفة والحجز | قبل تنفيذ المخزون؛ سياسة اختبار صريحة للإثبات |
| O04 | الحسابات والاعتراف والضرائب والفترات والتصحيح | قبل تنفيذ المحاسبة؛ نموذج اختبار محدود للإثبات |
| O05 | الترقيم والتخصيص والسداد والاعتمادات | قبل تنفيذ المستندات المعنية |
| O06 | المصادقة والدعوات والتفويض المحلي والإلغاء | قبل تشغيل متعدد المستخدمين |
| O07 | التخزين والعزل والقيود والفهارس والمعاملات | قبل اعتماد المخطط الفيزيائي |
| O08 | البروتوكول والسلطة المشتركة والتعارض وإعادة المحاولة والاحتفاظ | قبل تنفيذ المزامنة |
| O09 | النسخ والاستعادة وأهداف فقد البيانات وزمن التعافي | قبل اعتماد الاستمرارية |
| O10 | التقنية والإصدارات والبناء والطباعة والباركود والمنصات | بوابة القرار 007 |
| O11 | إعدادات التوريث والتفعيل والتخصيص | قبل تنفيذ الإعدادات |
| O12 | البحث والواجهات والقياسات والذكاء والأتمتة والخصوصية | قبل تنفيذ كل قدرة |
| O13 | الترخيص والقطاعات المستهدفة والتوزيع | قبل الإصدار التجاري |
لا تعد القائمة قرارًا بحل أي بند. تفاصيل المسائل في VISION.md وDECISIONS.md وCORE-DESIGN.md هي المرجع؛ عند اكتشاف مسألة جديدة أضفها بدل التخمين.
## قراءة التوثيق
الرؤية ثم القرارات ثم تصميم الجوهر ثم هذا المرجع. معرفات القبول في الملفات الأصلية وفهرس CORE-DESIGN.md؛ كل نتيجة اختبار مستقبلية ترتبط بمعرف وحالة اختبار ودليل والتزام محدد. لا تعتبر المعايير اختبارات ناجحة.
